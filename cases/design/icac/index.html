ICAC — версии главной страницы для запуска института на Хайнане

Проект по разработке главной страницы для российского института, открывающегося в Китае (остров Хайнань).

На этапе исследования был проведен анализ китайских образовательных сайтов, по итогам которого сформирована целевая структура сайта. На базе этой структуры и утвержденного брендбука разработаны две локализованные версии главной страницы: китайская и европейская.
