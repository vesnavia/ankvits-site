Новогодняя email-рассылка для Continent Express

Кейс по созданию новогодней email-рассылки для Continent Express, работающей в сегменте делового корпоративного туризма.

Описание кейса

В рамках проекта я разработала концепцию рассылки, написала тексты и собрала визуальный дизайн письма. В результате получился цельный материал для новогодней коммуникации с корпоративной аудиторией бренда.

Что сделано

  • Сформулирована концепция новогоднего письма для B2B-аудитории.
  • Подготовлены тексты рассылки с учетом tone of voice компании.
  • Разработан визуальный дизайн письма в едином праздничном стиле.
  • Собран финальный макет для корпоративной email-коммуникации Continent Express.
